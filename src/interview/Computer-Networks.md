## 1. What is a computer network, and why do we need computer networks?

A computer network is a collection of interconnected devices that can communicate and exchange data with each other
using communication protocols. We need computer networks to enable communication, data sharing, resource sharing, and
access to services such as the Internet

**Example** : For example, when I access a website, my computer communicates with a web server over a network to send a
request and receive the required data.

----

## 2. What is the difference between the Internet and a computer network?

A computer network is a collection of interconnected devices that communicate with each other, and it can range from a
small local network to a large enterprise network. The Internet is a global network of interconnected networks that
allows devices and networks around the world to communicate with each other.

**So, is the Internet a computer network?**
Yes. The Internet is essentially a global network of interconnected networks.
